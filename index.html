Air Canvas AI

Touchless drawing, powered by your webcam and hand-tracking — runs entirely in this browser tab.

Gestures

  • Index only — draw Brown
  • Middle only — draw Blue
  • Ring only — draw Green
  • Thumb only — Eraser
  • Fist — no drawing

Only the finger you want active should be extended — the rest curled in. A relaxed pointing hand with the thumb slightly out still counts as "index only."

How it works

Each frame is analyzed by MediaPipe's HandLandmarker (running fully on-device via WebAssembly) to find 21 hand landmarks. Simple geometry on those points decides which single finger is extended, which selects a color and moves the brush — the same logic as the original Python desktop version of this project.

Nothing is uploaded: video never leaves your device. Drawings save straight to your downloads.
