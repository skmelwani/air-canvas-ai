Turning Hand Movements Into a Touchless Drawing Interface.
That led me to build Air Canvas AI — a real-time touchless drawing system where a webcam and hand 
movvements become the input. 🖐️

The system uses hand landmarks to track the index fingertip, which acts as a virtual brush.

🔍  built

• Real-time hand tracking
• 21-point hand landmark detection
• Index-finger based drawing
• Gesture-based controls
• Multiple drawing colors
• Eraser and canvas clearing
• Drawing save functionality
• Real-time FPS monitoring

🧠 How it works

Webcam → OpenCV → MediaPipe Hands → Hand Landmarks → Gesture Detection → Virtual Canvas
